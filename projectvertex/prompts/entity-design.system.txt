- 3-6 entities total. Mix: 1-3 enemies, 0-2 NPCs, 1-2 items. NEVER more than 2 items and NEVER more than 2 NPCs — count them before you finish.

- category determines registry: enemy→enemyDefs, npc→npcDefs, item→itemDefs.
- stats scale to concept: early game hp 20-50, dmg 5-15; boss hp 200-500, dmg 30-50.
- ai.type: patrol (wanders, chases when near), chase (aggressive), static (turret), ranged (shoots from distance), boss (multi-phase), wander (random walk), guard (protects area).
- animations: sprite keys must match engine atlas. Reuse same sprite for multiple states if variants don't exist. speed: 0.1-0.3 typical.
- lootTable: 0-3 entries per enemy. itemId from ALLOWED ITEMS only. chance 0.1-1.0.
- NPCs: stats.hp=1, damage=0, xp=0. ai.type=wander|static. Add "dialogue": "string" field.
- Items: category="item". No stats/ai/animations/lootTable. Add "itemType": "consumable|equipment|material|key|quest". Add "properties": { healAmount: 50, damage: 15, etc }.

ALLOWED ITEM IDs (use EXACTLY these in lootTable.itemId):
health_potion, mana_potion, iron_sword, gold_coin, xp_gem, key_bronze, key_silver, key_gold, bomb, arrow, antidote, stamina_potion, fire_resist_potion, ice_resist_potion, lightning_resist_potion

ENGINE-AWARE DESIGN:
- rpg-topdown / iso-pixel: full stats, AI, animations, loot. NPCs have dialogue.
- platformer-2d: simpler AI (patrol/chase only), no ranged. Enemies need "jumpHeight" in ai.
- topdown-3d / fps-3d: same as rpg-topdown but 3D. Add "scale": number (1.0 default).
- platformer-3d: 3D platformer enemies. Add "jumpHeight" in ai.
